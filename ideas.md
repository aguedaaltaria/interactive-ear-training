# 🚀 Ideas y Mejoras Futuras para el Entrenador Auditivo

Este documento contiene sugerencias de funcionalidades avanzadas que fueron pausadas o reservadas para futuras versiones, permitiendo que la versión 1.0 se mantenga estable y enfocada en el entrenamiento auditivo base.

## 🎵 Nuevas Mecánicas de Juego y Teoría
- **Dictado Melódico:** El motor de audio toca una secuencia de 3 o 4 notas y el usuario debe replicarla en el orden exacto.
- **Nomenclatura Avanzada (Slash Chords):** Mostrar el cifrado exacto del acorde generado con sus inversiones (ej. Do Maj9 / Mi) en la pantalla de resultados para conectar el desarrollo auditivo con la teoría musical visual y moderna.

## 🏆 Interactividad y Competencia
- **Modo Multijugador en Tiempo Real (WebSockets):** Implementar salas de duelo o retos simultáneos donde dos estudiantes escuchen el mismo acorde al mismo tiempo y compitan por adivinarlo primero, utilizando WebSockets para la comunicación bidireccional en vivo.
- **Ranking Global (Salón de la Fama):** Una pantalla que sume los puntos totales de todos los usuarios registrados en la base de datos SQLite y muestre un "Top 10" para añadir un factor competitivo entre estudiantes.

## 🎨 Mejoras de Interfaz (UI/UX)
- **Integración Visual Musical:** Reemplazar o acompañar la cuadrícula de botones con un teclado de piano interactivo que se ilumine, o integrar una librería que dibuje la respuesta correcta en un pentagrama clásico.
- **Panel de Configuración del Jugador:** Un menú de ajustes donde el usuario pueda controlar el volumen maestro, elegir la velocidad de reproducción de los acordes (lento/rápido) y activar un "Modo Oscuro" para la pantalla.
